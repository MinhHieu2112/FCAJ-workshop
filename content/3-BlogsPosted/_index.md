### [Blog 1 - Authentication System with AWS Cognito](3.1-Blog1/)

This blog describes the integration of **Amazon Cognito** into a real estate rental management system, covering JWT-based authentication and role-based access control (**Manager** and **Tenant**) using `JwtAuthGuard` and `RolesGuard`. It also discusses the challenges of working with Access Tokens and ID Tokens, as well as the optimized authentication workflow in a Next.js and NestJS application.

### [Blog 2 - Image Management with Amazon S3](3.2-Blog2/)

This blog explains how **Amazon S3** is used to store and manage property images efficiently. It covers image uploads using Presigned URLs, access control through AWS IAM, storing image URLs in PostgreSQL, and optimizing image delivery with the Next.js `Image` component.

### [Blog 3 - Maps and Location Services with Amazon Location Service](3.3-Blog3/)

This blog introduces the integration of **Amazon Location Service** and **MapLibre GL JS** to implement interactive maps in the system. It explains the geocoding workflow, property location visualization, IAM-based access control, and practical experiences with AWS Signature Version 4 (SigV4) and geocoding optimization during development.
