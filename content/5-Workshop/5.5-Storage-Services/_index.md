#### Overview

This module covers three AWS managed services that extend the core application functionality:

- **Amazon S3** – Secure property image storage using presigned URLs for direct browser-to-S3 uploads.
- **Amazon Location Service** – Address geocoding and interactive map tile rendering.
- **Amazon SES** – Automated transactional email notifications on application status changes.
